# iOS-приложение

Минимальный каркас AITU Booking на SwiftUI. Проект рассчитан на iOS 17 и новее.

## Запуск

1. Откройте `AITUBooking.xcodeproj` в Xcode.
2. Выберите симулятор iPhone.
3. Запустите схему `AITUBooking`.

Сейчас в проекте есть только точка входа и стартовый экран. Функциональные модули и ресурсы будут добавляться по мере разработки.
